## 🌟 Tentang SIGNARY

**SIGNARY** (sebelumnya bernama *Signia*) adalah platform ekosistem inklusif terpadu yang dirancang untuk memfasilitasi komunikasi dua arah serta pembelajaran bahasa isyarat (**BISINDO & SIBI**) secara mandiri dan interaktif.

Platform ini mengintegrasikan teknologi **AI Multimodal Real-Time** untuk mendeteksi gestur tangan, sistem kamus visual, modul akademi bertingkat, serta forum komunitas inklusif dengan antarmuka modern bertema *Liquid Glassmorphism* yang elegan dan ramah aksesibilitas.

---

## 🚀 Fitur Utama

### 1. 👁️ Live Interpreter (AI Multimodal Real-Time)
- Deteksi gestur tangan dan bahasa isyarat secara langsung menggunakan kamera.
- Visualisasi *hand skeleton keypoints* untuk panduan akurasi posisi tangan.
- Terjemahan instan gestur isyarat ke teks dan audio secara responsif.

### 2. 📚 Smart Dictionary (Kamus Isyarat Interaktif)
- Pustaka kosakata isyarat lengkap (BISINDO & SIBI).
- Dilengkapi demonstrasi visual, foto/video gestur, dan tips gerakan tangan.
- Fitur pencarian cepat dan penyaringan berdasarkan kategori.

### 3. 🎓 Sign Academy & Mini-Game Edukatif
- Modul pembelajaran berjenjang dari tingkat dasar hingga mahir.
- **Kuis Interaktif**: Evaluasi pemahaman dengan sistem skor XP dan feedback kunci jawaban.
- **Sign Match**: Mini game mencocokkan kosakata dengan deskripsi gerakan untuk melatih daya ingat visual.

### 4. 📊 Dashboard Analytics & Progres Belajar
- Monitoring perkembangan belajar: jumlah isyarat dikuasai, streak harian, dan total XP.
- Visualisasi grafik akurasi latihan dan evaluasi mingguan.

### 5. 💬 Inclusive Community (Forum Ramah Tuli)
- Ruang kolaborasi dan interaksi inklusif antara Teman Tuli dan Teman Dengar.
- Fitur berbagi tips, diskusi materi, dan pengalaman belajar.

### 6. ♿ Aksesibilitas & Personalisasi
- Mode ramah visual (kontras tinggi, pengaturan ukuran teks, dukungan pembaca layar).
- Desain antarmuka *responsive* untuk perangkat desktop, tablet, maupun mobile.

## 🛠️ Teknologi yang Digunakan

- **Frontend Core**: [React 19](https://react.dev/), [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) dengan custom *Liquid Glassmorphism* UI
- **Ikon**: [Lucide React](https://lucide.dev/)
- **Deployment**: GitHub Pages (dengan GitHub Actions Automated CI/CD)

## 💻 Panduan Menjalankan Secara Lokal

### Prasyarat
- [Node.js](https://nodejs.org/) (versi 18 ke atas disarankan)
- [Git](https://git-scm.com/)

### Langkah Instalasi
1. **Clone repositori**:
   ```bash
   git clone https://github.com/MIqbalZafarullah/SIGNARY.git
   cd SIGNARY
   ```

2. **Install dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan development server**:
   ```bash
   npm run dev
   ```
   Buka browser di `http://localhost:5173`

4. **Build untuk produksi**:
   ```bash
   npm run build
   ```
